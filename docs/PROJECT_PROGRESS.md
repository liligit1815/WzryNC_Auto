## 主要风险

- 游戏 UI 更新会降低模板匹配可靠性，需要持续维护真机截图回归集。
- OCR 准确率尚未用足量样本量化，不能仅凭少量成功案例判断已达发布标准。
- 不同 ROM、ROOT 管理器和分辨率可能影响截图、命令超时与亮度节点行为。
- 长时间循环中的服务重建、内存回收和异常恢复仍缺少完整验收记录。

详细目标、验收条件和技术方案见 `docs/APK_DEVELOPMENT_PLAN.md`；构建与发布步骤见
`docs/RELEASE_BUILD_GUIDE.md`。
